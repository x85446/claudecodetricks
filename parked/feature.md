## Context
Parse $ARGUMENTS to get the following values

- [number of test cases]: Minimum number of test cases to author (0 means none)
- [impact size]: How big the impact of the feature is where 1 is minor and 5 is major
- [description]: Description of the feature

## Tasks

1. Discombobulate the feaature [description]
2. If the feature is 3,4,5 interview the user with additional questions to understand the feature fully
3. Make a breif plan that is ready for the gatekeeper(s)
5. consult with the gatekeeper(s) regarding paradigm 1
6. refine the plan
7. execute the plan
8. ensure 'make test' will include the new test cases
