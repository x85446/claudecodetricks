## Interview Instructions

**To populate the service profile**, open a new Claude Code session and paste the
following prompt:

```
Read .claude/skills/codeconverter-01-service-profile/instructions.md.

Scan the codebase to propose a value for every field in the Profile section.
For each field, state your proposed value and the evidence you found for it
(file path and what you read there). Do not write any files yet.

After presenting all proposals, wait for me to confirm or correct each one.
Then write docs/codeconverter/01-service-profile/service-profile.md using the confirmed values.
Use the structure from .claude/skills/codeconverter-01-service-profile/instructions.md as the format.
```

The AI will scan the codebase, propose values for each field, and wait for
your confirmation before writing. This interview typically takes one short session.
