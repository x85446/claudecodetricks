## Constraints
- Context: the statusline's source is `dotfiles/statusline-command.sh`; `~/.claude/statusline-command.sh` is a symlink to it — the live line follows the checked-out branch, so a broken edit shows immediately.
- Context: every reader of plan state (statusline, triage, conductor, dashboard) reads only the key block above the first `## ` heading — write `status: queued` there.
- Contract: `status: queued` is the one "approved for unattended launch" marker; `phase: planned` stays. A human `/iterate <name>` runs any plan; the nightly tick and the conductor launch only queued, unblocked, or already-executing plans — never a bare yellow one.
- Contract: enrollment = `tick-source: launchd` in `./.claude/iterate/conductor.md` (per project); global switch = `~/.claude/iterate-run/nightly.json`; plist label `com.x85446.iterate-nightly`; logs `~/.claude/log/iterate-nightly/`; per-project lock `~/.claude/iterate-run/nightly/<key>.lock`.
- Contract: `loop-mechanism: external` means `/iterate` arms nothing and cancels nothing; the OS tick is the resumption loop.
- Contract: pause is a human verb (`/iterate pause`, `/ic pause|kill`). The executor's only exits are all-green, human-gate, blocked-on-operator (ladder exhausted on something only a human can supply) and the 5-cycle giveup. Machine time, VM hours and test duration are never blockers; `Cost: none` is the standing authorization. The slow tier stays out of the default finisher selection; a drifted slow case attributable to the plan is in scope and runs in-plan.
- Decision: launchd, never crontab — cron runs outside the gui session (no Keychain for Claude's auth, needs Full Disk Access for `~/workspace`, skips runs that fall during sleep); launchd runs a missed StartInterval on wake.
- Decision: never pass `--bare` to the child — hooks carry the heartbeat and chain-guard.
- Decision: tick cadence 10 minutes; `--permission-mode auto`; one child per enrolled project per tick, serialised per project by flock, parallel across projects.
- Decision: a refinement to a queued plan unstages it — "approved" refers to the content that was approved.
- Decision: orange is 256-colour 208 with a bright-yellow (93) 16-colour fallback, per the detection ladder in `skills/uxmaster-cli/color.md`; `⏰` carries no ANSI (emoji ignore it), so "enrolled but off" is spelled with a dim `off` word.
- Colour precedence in the statusline: red > magenta > cyan > bold green (executing, live) > dark green (executing, stalled) > orange > yellow > dim.
- Decision: stalled = `phase: executing` with the project heartbeat (`~/.claude/iterate-run/heartbeats/<root>`) older than `ITERATE_LIVE_SECS` (900s) or absent — the same test that already picks ⚙️ over ⚡. Dark green is 256-colour 28 with a plain-green (32) ANSI-16 fallback; live keeps bold green at every tier; `status:` arms (red/magenta/cyan) still win over both.
- Flags parse in every position (`skills/uxmaster-cli/grammar.md`); `iterate-run nightly` output is machine-first: silent on success, one fact per line.
- No dirty builds: commit before `make install`; `iterate-run version` must not read `-dirty`.
- Codex ports of the iterate family are `manual=true` — the nightly Codex sync will report them stale; this plan does not regenerate them.
- Root cause on record: this project's ⚙️ segment was empty because `.claude/iterate/plans/` did not exist (eclectus archived 2026-09-28; nothing recreated the directory) and `iter_root_for` required that exact path — "no plans" was true, but indistinguishable from "segment broken". Step 6 and the step-8 placeholder remove the ambiguity.
- License: launchd — macOS built-in; Go stdlib only; no new dependency.
- Cost: none — own code, the existing Claude subscription, Apple's scheduler.
- Depends on: `iterate-run` at `~/go/bin` (present, iterate-v3.3) and the `claude` CLI 2.1.289 with `-p`, `--permission-mode auto`, `--output-format json|stream-json`.
