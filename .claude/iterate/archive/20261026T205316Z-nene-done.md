The Conductor is its own entity: a stdlib-only Go project at `~/workspace/tmctech/conductor` (module `github.com/tmctec/conductor`, binary `conductor`), pushed to a private `tmctec/conductor` GitHub repo with one initial commit and no carried history, with its own build, tests, docs, dashboard (localhost:8421) and LaunchAgents. claudecodetricks keeps `iterate-run` (plans, run record, hooks, reports, plan graph, the 8420 dashboard) and contains no Conductor code, command, target, test or doc.
